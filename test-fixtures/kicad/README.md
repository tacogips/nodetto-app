no KiCad library, demo, or QA content and are licensed with this repository.

  Nodetto tests; not derived from any third-party board.
- `kicad5.kicad_pcb`: self-authored KiCad 5 syntax fixture for Nodetto tests;
  not derived from any third-party board.
