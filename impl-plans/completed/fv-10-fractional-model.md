## Intent

The executable model of `packages/core/src/fractional.ts` and its vectors. The
z-order model (fv-11) imports this Model file, so the signatures below are a
contract.

## Changes

- `formal/Nodetto/Fractional/Model.lean`, `namespace Nodetto.Fractional`, with exactly
  the design 6.1 signatures:
  `abbrev Key := List Nat`, `abbrev Rng := List Nat`, `def DIGITS : List Nat`,
  `isFractionalKey`, `randomDigitBetween (low high : Nat) (rng : Rng) : Nat × Rng`,
  `midpoint (lower : Key) (upper : Option Key) (rng : Rng) : Except String (Key × Rng)`,
  `keyBetween`, `keyAfter` (both `Except String (Key × Rng)`).
  - `randomDigitBetween`: take the head draw `u` (or 0 when empty, rest `[]`),
    `span := high - low - 1`, offset `min (u * span / 2^20) (span - 1)`, result
    `low + 1 + offset`. This is the fixed TS behaviour (design D6/B2).
  - `midpoint` mirrors the TS branches in order: inverted-bounds error, shared-prefix
    recursion (`(lower[i] ?? "0") === upper[i]` with code unit 0x30 as the pad),
    room at the first digit, truncation `upper.take 1`, descent
    `DIGITS[low] :: midpoint lower.tail none`. Terminate with `termination_by` on
    `lower.length + (upper.map List.length).getD 0` (or a well-founded measure);
    no `partial`.
  - Digit lookup returns the index in `DIGITS` (`List.idxOf`); a non-digit cannot reach it.
  - `keyAfter none` = `midpoint [] none`; a valid key -> `midpoint s none`; otherwise
    `s ++ [DIGITS[randomDigitBetween 0 62]]`.
- `formal/Nodetto/Fractional.lean`: `import Nodetto.Fractional.Model` only.
- `formal/Nodetto/Fractional/Vectors.lean` (replaces the stub): imports
  `Nodetto.Json` and `Nodetto.Fractional.Model`; `main` prints the document with
  `module "fractional"`, sources `["packages/core/src/fractional.ts"]`.
  Cases (at least 20 each, 200+ total): `isFractionalKey {value}`;
  `keyBetween {before, after, draws}` (null for absent); `keyAfter {last, draws}`.
  `out` is `ok` with the key string or bool, or `err "range"`. Include: empty key,
  trailing `0`, non-digit, keys ending in `z`, shared prefixes (`"1"`/`"101"`),
  adjacent digits, inverted and equal bounds, foreign keys for `keyAfter`, draws
  `0`, `2^20 - 1`, and draw lists shorter than needed.
- `formal/vectors/fractional.json`: generated by the exe, committed.

## Pitfalls

- JS compares strings by code units: use `List.lt` on `List Nat`, never `String`.
- Keep the TS order of checks (`before` validity before `after`).
- `DIGITS[i]` lookups must be total (`getD`), never `!`.
- Do not write proofs here (fv-20/fv-21).
