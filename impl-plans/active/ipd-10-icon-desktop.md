## Intent and context

`ui.icon` renders in export (`ipd-07`) but not on the desktop canvas. This plan adds:

- the canvas view;
- the inspector section (name with search, color, stroke width; size uses the existing geometry section);
- a reusable `IconPicker` component. The palette plan `ipd-17` mounts it.

## Non-goals

- Do not edit `shape-palette.ts` or `ShapePalette.tsx`; `ipd-17` owns them.
- No new icon data.
- No changes to core.

## File-level changes

New `packages/ui-solid/src/shapes/IconView.tsx`:

- Renders the element box as an `<svg>` group, using `renderIconMarkup`/`renderIconPlaceholder` from `@nodetto/core` with the same paint resolution as export (`ipd-07`).
- Insert the markup with Solid's `innerHTML` on a `<g>`. The markup is generated by core with escaped attributes; custom paths are restricted by the IR character check.

`packages/ui-solid/src/shapes/ShapeView.tsx`: add `<Match when={props.element.type === "ui.icon"}>` next to the `ui.control` match (`:220`).

New `packages/ui-solid/src/inspector/IconSection.tsx`:

- Name field: a text input that shows up to 8 `searchIcons` suggestions as you type. Choosing one updates `semantic.icon`. Invalid names show the inline error from validation.
- Color: the existing color control used by `StrokeSection.tsx`, writing `style.stroke`.
- Stroke width: a number input, 0.25-6, step 0.25, writing `style.strokeWidth`.
- Custom path mode: a textarea for `semantic.path`. Switching modes clears the other field.
- Use the inspector write helpers in `packages/ui-solid/src/inspector/write.ts`.

`packages/ui-solid/src/Inspector.tsx`: mount `IconSection` for a single selected `ui.icon`, following how `UiControlSection` is mounted.

New `packages/ui-solid/src/IconPicker.tsx`:

- `export function IconPicker(props: { onPick: (name: string) => void; onClose: () => void })`.
- A search input (autofocus) and a grid of up to 120 results from `searchIcons`. Each cell renders the icon at 24 px with `renderIconMarkup`, and has an `aria-label` with the name.
- Keyboard: arrow keys move, Enter picks, Escape closes.
- Styles go in the new `packages/ui-solid/src/IconPicker.css`, using the existing chrome tokens from `apps/desktop/src/styles` variables. Use no hard-coded colors outside those tokens; see `design-appearance.md` section 4.

## Patterns to imitate

- `packages/ui-solid/src/shapes/UiControlView.tsx` for a node view.
- `packages/ui-solid/src/inspector/UiControlSection.tsx` for a section.
- `packages/ui-solid/src/shape-search.ts` and `ShapePalette.tsx` for search UI.

## Pitfalls

- Do not call `iconNames()` on every render. Memoize results per query with `createMemo`.
- The canvas must not mount 1000+ SVGs. Cap the grid at 120 and refine by query.
- Keep `IconPicker` free of editor state; it only reports names.

## Tests

New `packages/ui-solid/src/icon-view.test.ts`:

- An `IconView` for `{icon:"bell"}` renders at least one `path` or `circle` element.
- An unknown name renders the dashed placeholder.

New `packages/ui-solid/src/icon-picker.test.ts`:

- Typing `bell` shows `bell` first.
- Enter calls `onPick("bell")`.
- Escape calls `onClose`.

Imitate the rendering setup in `packages/ui-solid/src/text-note-view.test.ts` and `shape-search.test.ts`.
