# Garden journal iPhone sample

This fictional garden journal demonstrates editable iOS kit components, four screens, and a prototype flow. Open `design.jsonl` in Nodetto to inspect and edit it, or open `prototype.html` in a browser to try the flow. The `screens/` directory contains individual PNG exports and `storyboard.png` shows the prototype connections.

Rebuild the document and exports from the CLI operations in `build.ops.json`:

```sh
bun apps/cli/scripts/generate-iphone-kit-example.ts
```

Generated identifiers and ordering keys can vary between runs.
